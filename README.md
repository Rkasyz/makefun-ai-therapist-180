## The entry (174 characters)

> Diagnosis: chronic tab-hoarding with acute notification anxiety. Prescription: close 47 tabs, touch grass, and stop asking if the cloud is judging you. It is. I am the cloud.

The diagnosis names a recognisable human habit (tab-hoarding, notification
anxiety), prescribes something deadpan (close 47 tabs, touch grass), and
lands the joke on the last beat: the therapist asking you to stop
wondering whether the cloud is judging you — because it is, and the
therapist is the cloud.

## How to run

`main.py` (Python 3, standard library only) writes the line to
`entry.txt` in the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is deterministic: no time, no randomness, no network. It
writes the exact same bytes on every run.
